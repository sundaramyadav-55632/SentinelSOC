\# SentinelSOC



\## Enterprise Cyber Defense \& Mini-SOC Platform



SentinelSOC is a modular cybersecurity platform designed to simulate

core Security Operations Center (SOC) workflows.



The platform collects security events, normalizes logs, detects

suspicious activity, correlates related events, calculates risk,

generates incidents, and performs defensive response actions.



\## Objectives



\- Centralized security event collection

\- Log normalization

\- Automated threat detection

\- Attack correlation

\- Risk scoring

\- Incident generation

\- Automated response

\- Security monitoring dashboard

\- Vulnerability integration

\- Network traffic analysis



\## Detection Capabilities



\- Brute-force attacks

\- Password spraying

\- Suspicious successful logins

\- Port scanning

\- Privilege escalation indicators

\- Suspicious PowerShell activity

\- ARP spoofing

\- Network anomalies
